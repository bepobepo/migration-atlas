# Function and data review — 4 November 2026

## Corrected defects

- Arrows and arrowheads grew with SVG zoom; marker size also multiplied by line width. Lines now use non-scaling strokes capped at 2.4 screen pixels. Markers use explicit user-space sizing compensated for zoom and viewport scale, keeping a 7-pixel marker. Country points and endpoint labels are similarly compensated. This is covered by desktop/mobile viewport and zoom calculations in the interaction tests; live browser rendering remains unverified.
- Added inclusive custom ranges from 1960–2024, including single years, using annual source values. Existing five-year shortcuts remain. Map labels, tooltips, pair details, reverse flows, country immigration/emigration totals and historical drivers share the same selected range. Partial failures show no total. A later request cannot be overwritten by a slow earlier range.
- Historical drivers now filter to the selected route/direction and overlapping years. Reading a period event preserves the range and offers a return to the figures. The source supports historical context, not a numerical attribution of migrations to individual causes; uncurated routes remain explicit gaps.
- A user screenshot exposed four incorrect country identities in the reference import. Natural Earth's ISO_A3_EH is shared by some dependent/disputed features: later entries overwrote FRA (France) with Clipperton Island, AUS (Australia) with Ashmore and Cartier Islands, BRA (Brazil) with Brazilian Island, and KAZ (Kazakhstan) with Baikonur. Corrected both names and map endpoints and rebuilt the browser metadata. The new pinned reference extractor groups duplicate codes and requires a unique matching ADM0_A3 country feature; ambiguity fails instead of silently overwriting. All 252 extracted reference entries were compared with the previous file: only those four identities changed.
- Touch-closing an arrow tooltip previously restored focus to an SVG path, allowing a large native focus rectangle on mobile. Pointer dismissal now clears popup focus without focusing the path. SVG focus outlines and tap highlights are explicitly suppressed; keyboard focus still returns to the route and uses a non-scaling stroke highlight. DOM checks verify both input paths, but the reported mobile rendering could not be reproduced in a live browser here.
- Country-pair figures now show the dataset, model-versus-observation distinction, source country codes and methodology links directly below the figures.
- 29 source countries had missing map endpoints; their routes could be listed without visible arrows. Their names also appeared as ISO3 codes because Intl.DisplayNames expects ISO2 region identifiers. Added a checked Natural Earth name/coordinate reference, tiny-country markers, and canonical ISO mapping (including Palestine).
- Play stopped immediately at the default 2020–2024 interval. It now starts again at 1950 and advances in five-year steps.
- A failed earlier request could overwrite a newer timeline selection. Both success and failure now check request identity; old arrows disappear while a new period loads.
- Changing direction could leave a selected route outside the filter. Selection now resets on direction/search changes; event navigation clears stale search text.
- Repeated renders could duplicate trend bars and accumulate empty SVG groups. Detail requests are versioned and map layers are replaced cleanly.
- Estimated-zero routes could be drawn when selected; zero remains visible in the list but never creates a quantitative arrow. Missing trend observations have a separate hatch style.
- Controls could run before required assets loaded. They remain disabled until initialization completes.
- Fixed the ONS 2004 enlargement citation's 404 URL and updated the Ukraine UNHCR citation to its indexed canonical URL. Added a contemporary UNHCR source for the Venezuelan migration context.

## Quantitative audit

Independently reconciled all 961,480 annual aggregates across 65 years and all 192,296 five-year aggregates against the archived FLOW v1.0 CSV, using integer tenths derived with Decimal. Zero value mismatches, zero duplicate input year/sex records and zero incomplete groups. Expected coverage is derived independently from UN M49 and the source rows, so missing exported routes are checked as well as values. All exported corridors have a European endpoint. The data checksum matches the archived version. Existing five-year numerical estimates were not changed by this review.

All 194 source country codes are present in the independent UN M49 reference. Display names match either its name or one of 27 explicitly reviewed name variants; regional classifications have zero mismatches. All 205 map identities and endpoints match their canonical Natural Earth administrative country feature, and all 177 rendered polygon labels match the metadata. No additional identity collisions were found. The 11 geographic features without FLOW estimates are Western Sahara, Falkland Islands, Greenland, French Southern and Antarctic Lands, Puerto Rico, New Caledonia, Taiwan, Antarctica, Northern Cyprus, Somaliland and Kosovo. Their absence is now visible in selectors and never interpreted as zero migration.

Independent inclusive-range examples from the original CSV: Italy → France, 1999–2003 = 146,384.1; Italy → France, 2021 = 15,237.9; Belarus → Poland, 2020–2022 = 13,704.8; all covered origins → Poland, 2020–2022 = 1,375,926.5. Display figures use three significant digits and remain modelled estimates.

The earlier review checked name presence and coordinate ranges, which did **not** establish correct country identity and missed the four collisions described above. The corrected audit adds independent expected names and geographic bounds for these countries and verifies their selectors, map labels and Italy–France detail display. Reconciliation was rerun after regeneration. Source ITA → FRA sums to 774,041.6 and FRA → ITA to 512,195.5 over 1960–1964 (female plus male estimates). These are the figures previously mislabelled as migration involving Clipperton Island, not evidence of migration to that island. All thirteen quantitative JSON files remain byte-for-byte unchanged.

The preparation script now validates its input checksum before writing, rejects duplicate year/sex records, checks all ten observations per period, and exports only after validation. `tests/data_test.py` independently verifies the output without invoking the preparation implementation.

## Source suitability and historical review

FLOW is modelled migration, not observed counts. The original README explicitly describes detailed individual-corridor analysis and replacing official records as its least suitable uses. This is a material limitation of the app as a route-level research tool, even though its aggregation is correct. Methodology and route details now state it more directly. Five-year sums can include repeat migrants. Estimated zero is not proof of no movement. 1950–1959 remain an explicit quantitative gap.

Checked all eighteen primary citation URLs. Eleven originally returned content directly, one was a confirmed 404 and has been repaired, and six returned access restrictions/rate limits or a timeout. Indexed primary-source pages corroborated the Hungarian, Ugandan, Angolan, Colombian and Ukrainian contexts. The Bosnia chapter was identified in UNHCR's index, but its full PDF could not be re-fetched due to rate limiting. These access failures are not evidence that the historical accounts are false. Readable government sources support the recruitment, Polish/Romanian mobility, Spain/Germany, and Belarus stories. The Canary government PDF was downloaded and its chronology checked; Venezuela also now links to a contemporary 2019 UNHCR account.

Historical event periods are editorial focus periods, not proof of exact wave start/end dates or quantified causation. Administrative counts, nationality statistics, population stocks and modelled movement estimates remain distinct.
